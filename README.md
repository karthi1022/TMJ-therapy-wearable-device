# TMJ (Jaw Joint) Therapy Device

A dedicated wearable medical therapy device engineered to provide controlled massage therapy for Temporomandibular Joint (TMJ) pain management.

## Hardware & Components
- Microcontroller: ESP32
- Actuators: Miniature vibration motors
- Power: Rechargeable Li-ion battery circuit

## Tech Stack
- **Firmware:** Real-time Embedded C
- **Features:** Timed therapy cycles

##  Key Highlights
- Controlled massage cycles tailored for delicate facial joints.
- Ultra-compact, low-power wearable form factor.
